## ⚠️ Disclaimer
**This is a demo project built strictly for educational purposes only.** 

Sona Movies does not host any files, media, or copyrighted content on its own servers. All media streamed through this application is provided by third-party federated APIs and external streaming providers. This project is a front-end UI/UX demonstration of a cinematic streaming interface and a digital library integration.

---

## 🌟 About The Project
Sona Movies is a premium, cinematic web application that blends a high-end streaming service interface with a fully integrated digital library and e-reader. Built with modern web technologies, it focuses on delivering a buttery-smooth, high-FPS user experience through stunning "3D Water Droplet" glassmorphism UI elements.

### ✨ Key Features
- **Cinematic UI/UX:** Stunning 3D water droplet glassmorphism effects, floating elements, deep shadows, and high-FPS hardware-accelerated micro-animations.
- **Federated Streaming Hub:** Aggregates trending movies, regional cinema (Hindi, Bhojpuri, South Indian Dubbed), and TV shows into a unified interface.
- **My Library Dashboard:** A dedicated space to browse, discover, and directly read public domain and federated books via an integrated premium e-reader layout.
- **Live TV & Shorts:** Immersive Live TV viewing and a vertical video "Shorts" player.
- **Responsive Design:** A fully responsive grid and slider system that looks beautiful on massive desktop monitors down to mobile screens.
- **Secure Architecture:** The application does not download, torrent, or scrape illegal content. It relies strictly on standard API endpoints.

## 🚀 Built With
- React.js (Vite)
- Custom Vanilla CSS (Design Tokens, Glassmorphism, CSS Variables)
- TMDB API Integration
- FreeBooksAPI & OpenLibrary (Federated Book Providers)
- React Router Dom

## 🛠️ Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/sonusah88/Sona-Movies.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

*Note: Environment variables for API keys must be provided locally in a `.env` file (which is intentionally git-ignored for security).*
